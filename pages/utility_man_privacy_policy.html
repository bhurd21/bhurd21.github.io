Last updated: June 28, 2026

Utility Man is a Chrome extension that helps users solve the Immaculate Grid baseball puzzle. This policy explains what data the extension handles.

Data collected

Utility Man does not collect, store, or transmit any personally identifiable information. The extension does not track users, does not use analytics, and does not maintain any user accounts.

How it works

When you visit the Immaculate Grid, the extension reads the grid cell labels from the page (e.g. "Boston Red Sox + Gold Glove") and sends them to a self-hosted API at brennanhurdgmail.com. The API queries the Lahman baseball database and returns a ranked list of qualifying players. No user identity is associated with these requests.

Local storage

The extension uses chrome.storage.local to save two preferences on your device:

  • Whether answers are hidden by default
  • Your selected color theme (System / Light / Dark)

This data never leaves your device.

Third-party services

The extension links to player pages on Baseball Reference. Following those links is subject to Baseball Reference's own privacy policy.
